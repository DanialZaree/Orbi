
# Orbi ChatBot

> **⚠️ Disclaimer:** This is just a demo project built for learning and demonstration purposes.

ORBI ChatBot is an advanced AI conversational assistant designed for seamless interactions. Engage with ORBI to get answers, brainstorm ideas, and chat in real-time in a dynamic, responsive environment.

## Overview

Orbi is a modern full-stack web application that showcases the integration of generative AI within a custom web interface. It allows users to securely log in, interact with an AI model, and save their chat history.

### Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS, Framer Motion (GSAP), React Router (Wouter), and Markdown rendering
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (via Mongoose)
- **AI Integration**: Google Generative AI (Gemini)
- **Authentication**: JWT, Google OAuth

### Features
- 🤖 **Intelligent Chat**: Powered by Google Generative AI for smart, context-aware responses.
- 🎨 **Modern UI**: A sleek, animated user interface built with Tailwind CSS and GSAP.
- 🔒 **Secure Auth**: Custom email/password login and JWT-based authentication.
- 📝 **Markdown Support**: Renders code blocks, math (KaTeX), and rich text seamlessly.
- 📱 **Responsive**: Fully optimized for both desktop and mobile devices.
